# SportsViblee 전체 재설치본

저장소 내용을 전부 지운 뒤 이 ZIP의 내용물을 저장소 루트에 그대로 업로드하면 됩니다.

포함:
- index.html
- about.html
- 404.html
- CNAME
- columns/ssg-ad-visibility.html
- columns/yanggu-sports-marketing.html
- columns/wadipass-scarnon.html
- assets/site.css
- assets/site.js
- assets/site-config.js
- assets/comments.js
- assets/wadipass-scarnon-thumb.jpg
- Supabase 댓글 SQL 파일

반영:
- 예전 정상 사이트의 네이비→붉은 그라데이션 메인 배경/색상 복구
- 브랜드명: 바이브코딩으로 바라본 스포츠산업
- 칼럼 3편 모두 포함
- 최신순: SCARNON → 양구 → SSG
- SCARNON 메인 카드: 사용자가 준 배트 사진
- 1·2·3편 모두 이름 / 댓글 / 댓글 남기기 입력폼 포함
- 댓글은 칼럼 URL별로 따로 저장
- 모바일 반응형 유지

업로드 주의:
ZIP 안에 있는 index.html, assets 폴더, columns 폴더 등이 GitHub 저장소 최상단에 바로 위치해야 합니다.
